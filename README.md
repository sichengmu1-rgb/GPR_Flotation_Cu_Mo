# gpr-flotation-cu-mo

Variogram-based Gaussian process regression applied to industrial
copper–molybdenum flotation data. A published GPR workflow, run
unmodified on 38 plant tests, predicts negative recoveries over 43% of
its interpolated domain. Three edits fix it.

Draft preprint: `paper/manuscript.pdf`

---

## Layout

```
data/mineral_x_dataset.csv    38 flotation tests
code/run_gpr.py               baseline: reproduces the published workflow
code/run_experiments.py       main experiment: baseline vs corrected
figures/                      four figures, generated by the scripts
paper/manuscript.pdf          8-page draft
```

## Run

```bash
pip install numpy pandas scipy scikit-learn matplotlib gstools scikit-gstat
python code/run_experiments.py
```

`gstools` and `scikit-gstat` are needed only for the baseline path;
the corrected workflow uses scipy and scikit-learn alone.

## Data

| Column | Meaning | Range |
|---|---|---|
| `grain` | Grinding fineness (−0.074 mm) | 40–75 % |
| `ph` | Pulp pH | 3.5–11 |
| `diesel` | Diesel collector dosage | 50–200 g/t |
| `time` | Conditioning time | 5–25 min |
| `mo_rec` | Mo recovery | 7–58 % |
| `cu_rec` | Cu recovery | 2–52 % |
| `src` | Which test series | — |

Values were recovered from Origin objects embedded in a source `.docx`,
not from a published spreadsheet. The campaign varied one factor at a
time, so the points sit on coordinate axes rather than filling the space.

## Scripts

`run_gpr.py` reproduces the published workflow end to end: scale, PCA to
two components, fit variograms, ordinary kriging with an isotropic exact
kernel, conditional simulation, inverse transform, Pareto frontier.

`run_experiments.py` is what generates every number in the paper. Section
A reproduces the baseline and counts out-of-range predictions. Section B
fits an ARD kernel per response with a learned nugget
(`ConstantKernel * RBF(length_scale=[...]) + WhiteKernel`) and reports
leave-one-out `Q²`, RMSE and CRPS. Section C samples 400 posterior
realisations to test whether the Pareto frontier is reproducible, then
replaces it with `P(y₁ ≥ q₁ ∧ y₂ ≥ q₂) ≥ 1−α`.

Key helpers: `crps_gaussian`, `q2_rmse`, `pareto_mask`, `fit_ard_gp`,
`loo_predict`. Writes `results.json` and four figures into `figures/`.

## Results

**Baseline**

```
Mo recovery  [−110.9, +65.7] %   →  42.7 % outside [0,100]
Cu recovery  [ −70.3, +70.5] %   →  16.5 % outside [0,100]
Pareto frontier: 5 points, 0 of 400 realisations reproduce it
```

**Corrected, leave-one-out**

| Response | ARD length scales | σₙ | Q² | RMSE | CRPS |
|---|---|---|---|---|---|
| Mo | [0.106, 0.019, 0.260, 0.246] | 0.640 | 0.385 | 10.58 % | 6.23 |
| Cu | [1.529, 0.214, 0.796, 0.243] | 0.463 | 0.668 | 5.93 % | 3.30 |

Inverse length scales for Mo are `[9.46, 52.54, 3.84, 4.06]`, so pulp pH
dominates by 5.5× over the next predictor. Cu ranks them differently. An
isotropic kernel cannot express either.

**Reliability window** (Mo ≥ 23 %, Cu ≥ 35 %): 44 grid points at 50 %
confidence, 8 at 75 %, none at 90 %. Best point — fineness ≈ 70 %, pH
≈ 7.0, diesel ≈ 100 g/t, time ≈ 15 min → Mo 45.7 ± 9.9 %, Cu
41.3 ± 5.0 %, joint confidence 0.88.
